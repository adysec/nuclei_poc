🚀 快速开始

克隆即用，三行命令开始扫描

克隆仓库bash
git clone https://github.com/adysec/nuclei_poc
cd nuclei_poc
扫描目标站点bash
# 全量扫描
nuclei -t poc/ -u https://example.com

# 按类别扫描
nuclei -t poc/cve/ -u https://example.com
nuclei -t poc/wordpress/ -u https://example.com

# 精品集（按梯度选择，数值越大质量越高）
nuclei -t poc_gold_11/ -u https://example.com
nuclei -t poc_gold_13/ -u https://example.com
nuclei -t poc_gold_15/ -u https://example.com
